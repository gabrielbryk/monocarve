# Security policy

## Supported versions

Until the first public release, only the latest commit on the default branch is
supported. After releases begin, this file will identify the supported release
line explicitly.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Use the repository's
private vulnerability-reporting feature under **Security → Advisories → Report a
vulnerability**.

Include the affected command or component, reproduction steps, expected impact,
and any suggested mitigation. Please avoid accessing data you do not own or
running a proof against third-party repositories without permission.
